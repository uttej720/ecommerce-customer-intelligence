Visualisation standards

Only final, readable PNG files will be included in this folder.

Visuals must:

Use clear, business-focused titles

Include readable labels and legends

Present aggregated, non-identifying results only

Avoid raw transaction data and customer-level personal information

Avoid screenshots containing database credentials or raw data grids
